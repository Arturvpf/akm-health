# Internal working records (Portuguese)

These files are the team's internal task records, written in Portuguese while the work was in progress. They are **not part of the submission documentation**: the English documents in `docs/` and the root `README.md` are authoritative. Where code, tests and these records disagree, the code on `main` is the source of truth. Some route names and message texts in these records predate the English route identifiers (`#/register`, `#/history`, `#/investigation`).
